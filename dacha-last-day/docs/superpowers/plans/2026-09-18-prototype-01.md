# Prototype 0.2 Implementation Plan

**Goal:** Deliver a runnable Godot 4.7.2 vertical slice with Survival, four Tower Defence structures, perks and a miniboss.

**Architecture:** Scene-based actors with focused GDScript components. Main owns run flow; actors own local behavior. Assets are isolated SVG files for easy replacement by final production art.

**Tech Stack:** Godot 4.7.2, GDScript, SVG assets, GitHub Actions headless validation.
