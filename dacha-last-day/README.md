# Дача: Last Day — Prototype 0.1

Godot 4.7.2 2D survival roguelike + tower defence vertical slice.

## Управление
- WASD — движение
- ЛКМ — стрельба
- R — перезарядка
- Shift — рывок
- Во время фазы строительства: T — поставить картофельную турель (20 лома)

## Уже в прототипе
- Дядя Витя: движение, дробовик, перезарядка, dash, HP, XP, level-up
- Враги: курица-псих, кабан-таран, сосед-стрелок
- Волны Survival с ростом плотности
- XP-орбы и 3 перка
- Лом как ресурс
- Tower Defence build phase после каждой 3-й волны
- Автоматическая турель
- Отдельные SVG-ассеты для персонажей, оружия и окружения

## Запуск
Открыть `project.godot` в Godot 4.7.2 и нажать F6/F5.
