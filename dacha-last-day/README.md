# Дача: Last Day — Prototype 0.2

Godot 4.7.2 2D survival roguelike + tower defence vertical slice.

## Управление
- WASD — движение
- ЛКМ — стрельба
- R — перезарядка
- Shift — рывок
- Во время фазы строительства:
  - T — картофельная турель (20 лома)
  - G — мангал/огненная зона (18)
  - F — холодильник лечения (22)
  - B — баррикада (10)

## Уже в прототипе
- Дядя Витя: движение, дробовик, перезарядка, dash, HP, XP, level-up
- Враги: курица-псих, кабан-таран, сосед-стрелок
- Мини-босс Царь-Кабан на 5-й волне и далее каждые 5 волн
- Волны Survival с ростом плотности
- XP-орбы и 3 перка
- Лом как ресурс
- Tower Defence build phase после каждой 3-й волны
- 4 типа построек: турель, мангал, холодильник, баррикада
- Плавная смена дневной атмосферы к ночной во время волны
- Отдельные SVG-ассеты для персонажей, оружия, построек и окружения

## Запуск
Открыть `project.godot` в Godot 4.7.2 и нажать F5.
