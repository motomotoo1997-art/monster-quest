# ⚔️ Монстро-Квест

Браузерная игра-приключение в духе Nexomon и Pokémon: открытый мир, пошаговые бои, ловля монстров, магазин, квесты и легендарный монстр. Написана на чистом HTML/CSS/JavaScript — без библиотек и сборки.

## 🎮 Как играть

- Открой `index.html` в любом современном браузере — и всё!
- Или включи GitHub Pages (Settings → Pages → ветка `main`) и играй по ссылке.

**Управление:** стрелки / WASD или кнопки на экране. Подойди к персонажу или объекту, чтобы взаимодействовать.

## ✨ Возможности

- 🗺️ Открытый мир: луг, лес, озеро и горы — в каждой зоне свои монстры
- 🐾 24 оригинальных монстра с рисованной SVG-графикой и эволюциями
- ⚔️ Пошаговые бои: стихии, статусы (яд ☠️ / паралич ⚡ / сон 💤), PP приёмов
- ⚪ Ловля монстров: обычные и золотые монстроболы
- 🪙 Экономика: монеты за победы, лавка торговца Тоши
- 📖 Нексопедия — энциклопедия всех монстров с редкостью
- 🧓 Квест бабушки Зины и три тренера с наградами
- 🌟 Легендарный Нексолар — испытание после победы над чемпионом
- 🎵 Чиптюн-музыка и звуковые эффекты на WebAudio (без аудиофайлов)
- 💾 Автосохранение в localStorage

## 📁 Структура

```
index.html      — разметка страницы
style.css       — все стили
js/data.js      — данные: монстры, приёмы, SVG-арт, генерация карты
js/world.js     — интерфейс, магазин, Нексопедия, движение по миру
js/audio-fx.js  — музыка, звуки и визуальные эффекты боя
js/battle.js    — боевая система, прокачка, инициализация
```
